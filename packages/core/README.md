# @kivin/core

*English | [日本語](#日本語)*

The runtime core of kivin: router, dependency injection, modules, lifecycle, input validation, cookies, Server-Sent Events and WebSocket. Everything else plugs into it.

**Requires Bun 1.4.0 or later** (Bun only; it does not run on Node). Part of [kivin](https://github.com/nori-kamiya/kivin/blob/main/README.md), which is early-stage and may change before a stable release.

## Install

```bash
bun add @kivin/core @kivin/decorators @kivin/valibot valibot
```

You also need `@kivin/cli` (`bun add -d @kivin/cli`) as a dev dependency to generate the manifest.

## Usage

```ts
// app.ts
import { defineApplication, defineModule } from '@kivin/core';
import { Controller, Get } from '@kivin/decorators';
import { createValibotAdapter } from '@kivin/valibot';

@Controller('/hello')
export class HelloController {
  @Get('/')
  hello() {
    return { message: 'hello kivin' };
  }
}

const HelloModule = defineModule({ controllers: [HelloController], providers: [], imports: [] });

export default defineApplication({ modules: [HelloModule], schemaAdapter: createValibotAdapter() });
```

```ts
// main.ts
import { createApp } from '@kivin/core';
import manifest from './.kivin/generated/manifest';
import definition from './app';

// `manifest` is generated by `kivin generate --entry app.ts` (@kivin/cli)
createApp(definition, manifest).listen(3000);
```

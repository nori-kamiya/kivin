# @kivinjs/core

*English | [日本語](#日本語)*

The runtime core of kivin: router, dependency injection, modules, lifecycle, input validation, cookies, Server-Sent Events and WebSocket. Everything else plugs into it.

**Requires Bun 1.4.0 or later** (Bun only; it does not run on Node). Part of [kivin](https://github.com/nori-kamiya/kivin/blob/main/README.md), which is early-stage and may change before a stable release.

## Install

```bash
bun add @kivinjs/core @kivinjs/decorators @kivinjs/valibot valibot
bun add -d @types/bun typescript
```

kivin's type declarations need `"moduleResolution": "bundler"` in your `tsconfig.json`; `NodeNext` is not supported. `@types/bun` and `typescript` are needed for type checking.

You also need `@kivinjs/cli` (`bun add -d @kivinjs/cli`) as a dev dependency to generate the manifest.

## Usage

```ts
// app.ts
import { defineApplication, defineModule } from '@kivinjs/core';
import { Controller, Get } from '@kivinjs/decorators';
import { createValibotAdapter } from '@kivinjs/valibot';

@Controller('/hello')
export class HelloController {
  @Get('/')
  hello() {
    return { message: 'hello kivin' };
  }
}

const HelloModule = defineModule({ controllers: [HelloController], providers: [], imports: [] });

export default defineApplication({ modules: [HelloModule], schemaAdapter: createValibotAdapter() });
```

```ts
// main.ts
import { createApp } from '@kivinjs/core';
import manifest from './.kivin/generated/manifest';
import definition from './app';

// `manifest` is generated by `kivin generate --entry app.ts --outDir .kivin/generated` (@kivinjs/cli)
createApp(definition, manifest).listen(3000);
```

## 日本語

kivin の実行時の中核です。ルータ、DI、モジュール、ライフサイクル、入力検証、Cookie、Server-Sent Events、WebSocket を提供します。他のパッケージはこの上に載ります。

**Bun 1.4.0 以上が必要です**（Bun 専用で、Node では動きません）。[kivin](https://github.com/nori-kamiya/kivin/blob/main/README.ja.md) の一部で、early-stage のため安定版までに変わる可能性があります。

### インストール

```bash
bun add @kivinjs/core @kivinjs/decorators @kivinjs/valibot valibot
bun add -d @types/bun typescript
```

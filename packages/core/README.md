# @kivin/core

*English | [日本語](#日本語)*

The runtime core of kivin: router, dependency injection, modules, lifecycle, input validation, cookies, Server-Sent Events and WebSocket. Everything else plugs into it.

**Requires Bun 1.4.0 or later** (Bun only; it does not run on Node). Part of [kivin](https://github.com/nori-kamiya/kivin/blob/main/README.md), which is early-stage and may change before a stable release.

## Install

```bash
bun add @kivin/core
```

 Use `@kivin/cli` (`bun add -d @kivin/cli`) to generate the route manifest.

You also need `@kivin/cli` (dev) to generate the manifest, a schema adapter such as `@kivin/valibot`, and `@kivin/decorators` for controllers.

## Usage

```ts
import { createApp, defineApplication, defineModule } from '@kivin/core';
import { Controller, Get } from '@kivin/decorators';
import { createValibotAdapter } from '@kivin/valibot';
import manifest from '../.kivin/generated/manifest';

@Controller('/hello')
class HelloController {
  @Get('/')
  hello() {
    return { message: 'hello kivin' };
  }
}

const HelloModule = defineModule({ controllers: [HelloController], providers: [], imports: [] });
const definition = defineApplication({ modules: [HelloModule], schemaAdapter: createValibotAdapter() });

// `manifest` is generated by `kivin generate` (@kivin/cli)
createApp(definition, manifest).listen(3000);
```

## 日本語

kivin の実行時の中核です。ルータ、DI、モジュール、ライフサイクル、入力検証、Cookie、Server-Sent Events、WebSocket を提供します。他のパッケージはこの上に載ります。

**Bun 1.4.0 以上が必要です**（Bun 専用で、Node では動きません）。[kivin](https://github.com/nori-kamiya/kivin/blob/main/README.ja.md) の一部で、early-stage のため安定版までに変わる可能性があります。

### インストール

```bash
bun add @kivin/core
```

 ルートマニフェストの生成には `@kivin/cli`（`bun add -d @kivin/cli`）を使います。

マニフェストの生成に `@kivin/cli`（開発依存）、schema adapter（`@kivin/valibot` など）、コントローラ用に `@kivin/decorators` も必要です。
